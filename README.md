🛡️ AIG Shields Up Cybersecurity Job Simulation

Overview

This repository documents my completion of the **AIG Shields Up Cybersecurity Job Simulation through Forage**.

The simulation provided hands-on experience with cybersecurity tasks involving vulnerability analysis, security communication, and Python scripting. I completed activities centered around the **Log4Shell vulnerability** and a Python-based password recovery exercise.

> **Note:** This was a virtual job simulation completed through Forage and does not represent employment with AIG.

🐍 Project 2: Python Password Recovery

In this task, I developed a Python script that tested passwords from a wordlist against an encrypted ZIP archive in a controlled simulation environment.

The script iterates through possible passwords, attempts extraction, handles unsuccessful attempts, and identifies when the correct password is found.

Python Concepts Used

- Functions
- `for` loops
- File handling
- Binary file reading
- Exception handling
- ZIP file manipulation
- Conditional logic
- String decoding

Tools & Technologies

- Python
- PyCharm
- Python `zipfile` module
- Wordlist-based password testing

Source Code

The Python script can be found here:

**`python-password-recovery/bruteforce.py`**
